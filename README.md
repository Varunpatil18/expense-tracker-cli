# Personal Expense Tracker CLI

A lightweight, persistent Command-Line Interface (CLI) application built with Python to track, manage, and analyze daily spending habits.

## Features
- Object-Oriented Architecture: Modular classes (Expense, ExpenseTracker) separating data structures and application logic.
- Data Persistence: Automatically serializes and saves records to a local expenses.json file.
- Spending Analytics: Instant breakdown of total expenditure grouped by category.
- Defensive Error Handling: Validates numeric inputs and edge-case exceptions gracefully.

## Tech Stack
- Python 3
- Built-in Modules: json, os, datetime
